# Contributing

> **Audience:** Developers and maintainers
> **Purpose:** Contributing reference for Energy Usage.
> **Status:** Current documentation baseline
> **Release:** 0.1.0
> **Last Updated:** 2026-10-23

Contributions should follow current Home Assistant integration development
practices and include tests for behavioral changes.

Architecturally significant changes should consider whether an ADR is required.

Do not commit private energy data or credentials.

## Licensing

All source-code files must include the following SPDX license identifier at
the top of the file:

