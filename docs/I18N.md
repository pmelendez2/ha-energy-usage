# Internationalization

> **Audience:** Maintainers and contributors
> **Purpose:** Internationalization reference for Energy Usage.
> **Status:** Current documentation baseline
> **Release:** 0.1.0
> **Last Updated:** 2026-10-23

English is the initial supported locale for Energy Usage 0.1.0.
Home Assistant configuration and action metadata must use the integration
translation catalog (`strings.json` and `translations/en.json`).

Entity display strings should use Home Assistant entity translation support
when appropriate. Diagnostic messages for logs are not end-user labels.

The bundled Explorer is JavaScript and does not automatically inherit
Python integration translations. Its core control labels use a centralized English dictionary and the
English fallback. Other presentation and diagnostic strings remain English;
complete locale-aware Explorer translation remains open work.
Do not claim full multilingual Explorer support for 0.1.0.

Any additional language must preserve data, units, time-zone boundaries,
reading coverage, and calculations. No translation may invent readings.
