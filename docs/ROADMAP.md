# Roadmap

The roadmap is under development.

Initial areas include:

1. Home Assistant integration skeleton.
2. Connection to the energy ingestion service.
3. Historical electricity statistics.
4. Historical gas statistics.
5. Home Assistant Energy Dashboard validation.
6. Configuration flow.
7. Diagnostics and error handling.
8. Repeatable Home Assistant release compatibility testing.
9. HACS/public distribution preparation.

Detailed milestones and acceptance criteria will be defined separately.
