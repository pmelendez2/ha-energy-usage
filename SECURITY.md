# Security

> **Audience:** Users and administrators
> **Purpose:** Security reference for Energy Usage.
> **Status:** Current documentation baseline
> **Release:** 0.1.0
> **Last Updated:** 2026-10-23

The Home Assistant integration should not require direct access to utility
credentials when the ingestion service owns provider acquisition.

Do not commit credentials, tokens, private utility files, account identifiers,
or other sensitive customer information.
