# ha_energy_usage

Home Assistant integration for residential energy usage provided by the
energy ingestion service.

The initial UI target is the Home Assistant Energy Dashboard.

## Initial scope

- Whole-home electricity usage.
- Residential gas usage.
- Historical Home Assistant statistics.
- Home Assistant Energy Dashboard integration.
- Thin integration boundary to the energy ingestion service.

## Development baseline

Installation method:

- Home Assistant Container

Development and initial compatibility target:

- Home Assistant Core 2026.9.4
- Home Assistant Frontend 20260826.7

## Home Assistant compatibility

### Tested

- Core 2026.9.4
- Frontend 20260826.7

### Supported

The formal supported-version policy has not yet been established.

Each new Home Assistant release will have a repeatable compatibility validation
process. Tested and supported versions will be updated in this README.

## Platform

Initial development and testing:

- Ubuntu 26.04
- Linux
- Home Assistant Container

Windows and macOS are not currently supported or tested.
